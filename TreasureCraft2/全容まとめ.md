# トレジャークラフト2 全容まとめ(2026-11-09 時点)

> 数字・レシピ・手伝い・敵のデータは `data.js` から自動で書き出しています。ルールの説明は手で書いています。

## 0. ひとことで
- ターン制のサバイバル・クラフト。1回動くと1ターン、敵も1ターンずつ動く
- 目標は、異世界の魔王城にいる「魔王ヴォルガ」をたおすこと
- ランキング: 魔王をたおすまでの**ターン数が少ないほど上**

## 1. 目標の流れ(画面上に1行ずつ出る・全18段階)
1. 木を切って 木材を5こ集めよう
2. 作業台をつくって 置こう
3. 作業台で 木のつるはしをつくろう
4. 岩をこわして 石を8こ集めよう
5. 葉っぱを集めて 寝床をつくって置こう(夜にそなえる)
6. かまどをつくって置こう
7. かまどで木炭をつくって 作業台で松明をつくろう
8. かべで囲って松明をともした部屋で 朝まで眠ろう
9. 「ほる」で穴をほって、はしごをかけて地下へ行こう
10. 地下で銅鉱石を掘って、銅のかたまりをつくろう
11. 石のつるはし以上で 鉄鉱石を掘ろう
12. 鉄のつるはしをつくろう(星晶を掘るのに必要)
13. 地下B4より深い階で 星晶を6こ集めよう
14. 夜の山などにいる岩ゴーレムをたおして 大地の核を3こ集めよう
15. 作業台で 門をつくって 地上に建てよう
16. 門をくぐって 異世界へ行こう
17. 魔鉱石で 魔鋼をつくって 武器とよろいを強くしよう
18. 魔王城へ行って 魔王をたおそう

## 2. 世界
- フロアは7つ。どれも 1000×1000マスで端あり。世界コード(シード)から作る
  - 地上 / 地下B1〜B5 / 異世界
- 地上のバイオーム: 平原・森・砂漠・雪原・山(+池・林・岩場・畑・花畑)
- はじまりの場所のまわりには、林・池・岩場・畑が必ずある。少し歩くと洞窟の入口・小さな遺跡・大きな建造物
- 地下への行き方
  - 地上の草地・土・砂・雪と 地下の床は 素手(3回)か スコップ(1回)で掘れる。土(地上の砂は砂)が手に入り、穴があく → はしごをかけて降りる(降りた所は上りはしご)。となりが水なら 穴でなく水になる
  - 土・砂は「うめる」で 水や穴を うめられる(土の地面・砂の地面になる)。水が流れるしくみは ない
  - 洞窟の入口・地下の天然の穴から降りる(降りた所は上り階段)
  - B5より下はない
- 異世界へは、地上に「門」を建ててくぐる
- 視点: 水平15°回した斜め見下ろし。地図(M)は行った所だけ出る

### 地下の階ごとのちがい
- B1: 石炭・銅が多い、鉄は少し。コウモリ・洞くつグモ
- B2: 金・赤い石が出はじめる。モグラ兵が出る
- B3: マグマが出はじめる。金・赤い石が増える
- B4: かべが「深部のかたい岩」(鉄のつるはし以上)。星晶が出る。鉱石ゴーレム
- B5: 星晶がいちばん多い。天然の穴はない(いちばん下)
- 敵には階ごとのレベルがある(B1=Lv2 … B5=Lv6)。Lvが1上がるごとに HP+35%・攻撃+20%
- 視界: 地下は「つながった空洞+かべ1枚」だけ見える。かべの裏は見えない
  - 松明・ガラス・作業台などは向こうが見える(視線をさえぎるのは 岩・かべ・扉だけ)
- 明るさ: 地下はほぼ真っ暗。主人公のまわりは うす暗い。松明・光るきのこ・金のかべ・電球で明るくなる

## 3. 基本ルール
- 時間: 1日480ターン(昼320・夜160)
- 満腹度: 100から5ターンに1へる。0になると5ターンごとにHP-2
- HP: 100(よろいの裏地で増える)
  - 自然回復: 満腹70以上で4ターンに+1、30以上で8ターンに+1
- 眠る(寝床)
  - 夜に眠ると朝まで(全回復)、昼は少し休む(最大HPの40%)
  - 眠っている間も時間は進み、敵に襲われると起きる。囲いと明かりがあると安全
  - 最後に使った寝床が復活地点
- 死ぬと: 復活地点で生き返る。持ち物はその場に落ちる(上に乗ると自動で拾える)
- 水: 泳げる。息は40ターン、切れると毎ターンHP-3。泳ぎは半分の速さ
- 持ち物: 64枠(8枠×8段)。1枠99個まで。いちばん上の段が手持ち(1〜8キー)
  - 「ならべる」ボタンで、2段目から下を 装備品→矢→食べ物→素材→置く物 の順にそろえる
  - 持ち物があふれるクラフトはできない
- 「つくる」のボタンを押したままにすると 続けて作れる(ターンはふつうに進む)
- 装備: 剣・つるはし・斧・クワ・よろい・弓 を種類ごとに1つ
- 「つかう」: 持ち物と向いている相手から自動で決まる。使い方が2つあるときだけ2つ目のボタン(C)
- 方向キーを押しっぱなしにすると、そのまま掘り進む・切り進む
- 「つかう」(Z)を押したまま歩くと、足もとと前の畑に 持っている種をまいていく
- 魔物や動物をたおすと、落とし物がその場に荷物として落ちる(上に乗ると拾う)
- 荷物は 魔物の落とし物が2日、自分が死んで落とした荷物が5日で消える。まわり(2マス以内)に荷物が6こ以上あるときは いちばん近い荷物にまとめる
- 掘りかけ・切りかけ・爆発で傷ついたマスは、最後に傷つけてから1日たつと もとにもどる
- 敵の出現: 主人公から10〜17マス先。松明の近く(5マス)には出ない
- 敵の気づき方: 3マス以内は物音で。遠いと視線が通るときだけ
- セーブ: 10こまで。「はじめから」で新しい世界(名前は「◯月◯日 ◯:◯ にはじめた世界」)、「つづきから」で一覧から選ぶ。一覧で なまえを変えたり 消したりできる
- 「はじめから」で サバイバルモードか 回路モードを えらぶ。回路の世界も 10この枠に入り、一覧に「回路」の印がつく
- ニックネームは 魔王をたおしたとき(ランキングにのせるとき)に入れる
- 主人公の見た目: 男の子8・女の子8から設定/メニューでえらぶ(全部の世界で共通)
- 実績: 53個。世界が変わっても残る。図鑑はセーブごと

## 4. 操作
- 移動: 矢印 / WASD(Shift+矢印で向きだけ)
- つかう: Z / スペース / Enter、もう1つの使い方: C
- 弓: F / ほる: X / まつ: Q(押しっぱなしで 待ちつづける)
- 1〜8: 手持ちをえらぶ / E: 持ち物 / M: 地図 / Esc: メニュー / H: キー一覧 / G(押している間): マスの線
- 画面のボタンでも全部できる(スマホ用)

## 7. 道具の組み立て(作業台・部品で作る)

## 13. 回路(赤い石の粉)
- 赤い石(B2〜)を掘ると「赤い石の粉」。床か 置いたかべの上に「導線」を置ける
- 導線は 主人公が向いている方向(たて/よこ)に置かれる。となりの導線の はしに横から つなぐと L字に、すでに2本つながっていれば 十字になる。平行な導線は つながない
- 導線に向いて「向き」で 形をえらぶ(たて・よこ・十字・交差・L字4つ)。絵のボタンをタッチか 矢印とZで えらぶ。「はずす」で回収
- 置いた物の片づけ方は2つ。**はずす**(1ターン・道具いらず): 回路の部品(導線・スイッチ・感圧板・電球・リピーター・NOT素子・動く床・矢の発射台)、松明、はしご(下り)、水晶のランプ、宝石の王冠、光るきのこ、カーペット。これらは掘っても こわれない
- **こわす**(道具でたたく): かべ・柵・床・扉・作業台・かまど・金床・寝床・箱・ガラスなど。どちらも置いた物は もどる
- 信号の強さは16。1マスごとに1へり、16マスまで届く。1ターンに1マス進む(信号を切ったときも 1ターンに1マスずつ消えていく)。リピーター・NOT素子も 1マスぶん
- リピーター: 後ろから入った信号を 強さ16にもどして前へ出す。前からの信号は通さない(一方通行)。「向き」で向きを変える
- NOT素子: たてか よこの向き。片方のはしに信号が来ると 反対のはしは OFF、どちらにも来ていなければ 両はしに ON
- 導線・リピーター・NOT素子は 信号が来ると明るく光る
- 信号を出す物: スイッチ(ぶつかると ON/OFF)、感圧板(乗っている間 ON)
- 動く物: 電球(松明より広く光る)、動く床(1ターンに1マス)、高速で動く床(2マス)、矢の発射台(矢を入れておくと1本撃つ)
- 動く床は となりの動く床にも信号を伝える
- 動く床の上に落ちた荷物(たおした魔物の落とし物・産んだたまご)は 運ばれ、床の先に落ちる。そこに荷物があれば まとまる
- 動く床・矢の発射台は 向いている方向に置かれる。置いたあとも 何も持たないか 動く床・発射台を持って 前に立つと「向き」で向きを えらびなおせる(絵のボタン)
